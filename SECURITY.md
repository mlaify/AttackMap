# Security reporting

This repository follows the
[mlaify organization-wide security reporting policy](https://github.com/mlaify/.github/blob/main/SECURITY.md).

There is no bug bounty or paid disclosure program, no payment, rewards, or swag are offered,
and a report does not create an obligation to respond or fix. Windows is unsupported unless this
repository explicitly documents otherwise.

Use this repository's **Security** tab and select **Report a vulnerability** for a credible,
confidential vulnerability in this project. Use a public issue for ordinary bugs and support.
